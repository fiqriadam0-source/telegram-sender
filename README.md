# Free Fire MAX Lag Fix

Script ini dibuat supaya anda boleh letak terus dalam folder game Android dan ia berjalan semasa game aktif.

Target utama:
- resolusi 540p
- fps 60
- lebih ringan pada RAM / CPU
- kurang lag semasa bermain

Cara guna:
1. Salin fail fix_freefire_max_lag.sh ke dalam folder data game Android anda.
2. Contoh lokasi biasa:
   - /sdcard/Android/data/com.dts.freefiremax/
   - /sdcard/Android/data/com.dts.freefiremax/files/
3. Jalankan file itu dengan shell Android, launcher, atau task manager yang boleh execute .sh.
4. Script akan auto-detect bila game sedang berjalan dan optimize secara berkala.

Nota penting:
- Script ini bukan untuk ubah seting game secara automate.
- Untuk hasil terbaik, set grafik game anda sendiri kepada 540p dan 60 FPS di menu settings.
- Script ini membantu kurangkan beban sistem, bersihkan cache, dan menstabilkan CPU/RAM semasa game aktif.
- Jika telefon anda rooted, script akan cuba pakai mode performance.
- Jika bukan rooted, ia tetap boleh bersihkan cache dan tutup app berat di latar belakang.

Fail utama:
- fix_freefire_max_lag.sh

Cadangan tambahan:
- Tutup TikTok, YouTube, Chrome, WhatsApp, Instagram sebelum masuk game.
- Biarkan ruang simpanan minimum 15-20% untuk performa lebih stabil.
- Kalau lag berulang, restart telefon selepas beberapa sesi bermain.
